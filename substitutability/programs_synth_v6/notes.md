# Lessons from validation error analysis, one entry per accepted slot

## Slot 1 - Core Food Identity Match (variant 1/4) - val accuracy 0.6237
Slot 1 (identity, v1): head-noun of ingredient vs first USDA segment, word coverage, penalties for extra first-segment words and transformed-product words. Validation accuracy 0.624 (says yes 32%, too conservative). Errors: 100 false no, mostly correct matches where USDA word order is inverted or generic-to-specific: "stew meat" -> "Beef, stew meat", "chuck roast" -> "Beef, chuck, blade roast...", "ox tongue" -> "Beef, variety meats, tongue", "Pacific herring" -> "Fish, herring, Pacific", "crawfish" -> "Crustaceans, crayfish". Penalizing extra first-segment words hurts when USDA first segment is a category (Beef, Fish, Pork). False yes (43): perfect-identity pairs labelled no, e.g. cottage cheese -> "Cheese, cottage, lowfat" , "whole flaxseeds" -> "Flaxseed, ground", spaghetti sauce variants; these are state/processing differences, label noise-ish. Guidance: treat first USDA segment as category when it is a generic word (beef, pork, fish, cheese, nuts, oil) and match against all segments; do not penalise extra words; add synonym handling (crawfish/crayfish, plant-based/vegan); next programs should focus on state/form (ground vs whole, low-fat, cooked) rather than identity, which is largely saturated.

## Slot 2 - Core Food Identity Match (variant 2/4) - val accuracy 0.6447
Slot 2 (identity, v2): weighted token recall of ingredient core words (head weighted higher) in all USDA segments, plus penalties for unexplained leading-segment words and processed-form words. Accuracy 0.645, says yes 37%. Errors: 88 false no, 47 false yes. False no: head words matching only via category/synonym (shungiku -> Chrysanthemum, clementine -> Tangerines, favas -> Broadbeans, maize -> corn), and cut names (pork chop -> Pork loin chops, chuck roast -> Beef chuck roast, vegan mayo -> tofu mayo). False yes: exact-name matches labelled no where USDA entry has a different state or ingredient mix: "sage" -> a cookie brand, "tomato vegetable juice -> low sodium", "flour tortilla" -> Taco entree, "canned sirloin" -> raw steak, "cottage cheese" repeated. Guidance: add a synonym table (clementine/mandarin/tangerine, fava/broadbean), penalize branded/restaurant/entree USDA names (capitalised brand, Taco, Sandwich) hard, and check that USDA's first word is a food category rather than a different dish. Identity is nearly saturated near 0.64; later rubrics should use state/form/processing and compare raw vs cooked, canned vs fresh.

## Slot 3 - Core Food Identity Match (variant 3/4) - val accuracy 0.6596
Slot 3 (identity, v3): character-trigram Dice of ingredient phrase vs first three USDA segments (also reversed order), head-noun substring check, brand penalty. Accuracy 0.660 (best so far), yes-rate 38%. Errors: 82 false no, 47 false yes. False no: organ/cut pairs where USDA hides the head inside long hierarchy ("beef heart" -> "Beef, variety meats and by-products, heart", "lamb liver", "ox tongue", "pork chop" -> "Pork, fresh, loin ... (chops)", "chuck roast"), and synonyms (filberts/hazelnuts, chicken flats/wing, pomegranate seeds). Long USDA names dilute trigram scores. False yes: matches whose only difference is a state or different product: "hazelnut" -> "Oil, hazelnut", "lean ground turkey -> Turkey, Ground, raw", "cottage cheese" -> lowfat/lactose reduced, "sage" -> Spices, sage, ground, "tomato vegetable juice" low sodium. Guidance: for meat, require ingredient head AND organ/cut word to appear anywhere in USDA; penalise USDA starting with Oil/Syrup/Juice/Spices when ingredient lacks that word; penalise low fat/reduced/no salt/lactose reduced modifiers absent from ingredient. Remaining slots should shift to state/form, nutrition-like variants, and diet qualifiers.

## Slot 4 - Core Food Identity Match (variant 4/4) - val accuracy 0.7
Slot 4 (identity, v4): rule cascade starting at 10: -3.5 per missing core word, -3 if head missing, -4 if USDA first segment has a different form word (oil, juice, sauce), brand/dish penalty, diet-modifier asymmetry, small bonus when head is in first segment. Accuracy 0.700 (best), yes-rate 41%. Penalty/cascade style beats similarity style. Errors: 70 false no, 44 false yes. False yes: identity right but state differs (raw vs cooked/dried/ground): "fresh swordfish -> cooked", "whole flaxseeds -> ground", "canned sirloin -> raw steak", "chuck roast -> braised", "lean ground turkey -> Turkey, Ground, raw", plus "hazelnuts -> beaked (Northern Plains)" obscure variety. False no: synonyms/varieties (Bing cherries -> Cherries sweet, concord grapes -> American grapes, clementine -> tangerine, shungiku, plant-based -> Vegan) and brand names in USDA (Ritz, Wheat Thins, Powerade). Guidance: next rubrics should handle cooking-state mismatch explicitly (ingredient cooked/fresh vs USDA cooked/raw/dried/canned), treat variety words (Bing, concord, Atlantic, sweet) as ignorable modifiers, and treat parenthetical brand words in USDA as neutral. Keep penalty-cascade architecture.

## Slot 5 - Preparation-State Equivalence (variant 1/4) - val accuracy 0.7067
Slot 5 (prep-state v1): detects state groups (raw/cooked/fried/dried/canned/frozen/smoked/ground) in both strings, state score 4 if overlap, 3 for raw~ground, 0 otherwise, plus identity coverage and form-change penalties. Accuracy 0.707 (best), yes 35%. Errors: 78 false no, 32 false yes. False yes: state matches but a dietary or compositional modifier in USDA is not in ingredient: "cottage cheese" -> lowfat / no sodium added / lactose reduced (repeatedly NOT), "tomato vegetable juice -> low sodium", "spaghetti sauce -> fat free", "dried split peas -> from dried, fat added", "pinto beans from dried, no added fat", "lean ground turkey -> Turkey, Ground, raw", "applesauce -> Cookie, applesauce". False no: cooked ingredient -> cooked USDA with extra descriptors, variants, synonyms (clementine, shungiku, flats -> wing, jamun -> Java-plum), and canned/brand entries (Mission Foods tortillas, Malt-O-Meal cereal). Guidance: add penalty for USDA modifiers like low/reduced/fat free/no salt/fat added when ingredient lacks them; treat "from dried" as mismatch with dried; reward when cooked verbs in ingredient match USDA cooked verbs even with extra descriptors; treat brand-name USDA entries as neutral when core words match.

## Slot 6 - Preparation-State Equivalence (variant 2/4) - val accuracy 0.7211
Slot 6 (prep-state v2): residual-word approach. Identity coverage minus penalties for harmful USDA residual words (cooked, dried, low, fat, juice, sauce...) that the ingredient lacks, and for ingredient states missing from USDA. Accuracy 0.721 (best), but says yes only 27%: 91 false no vs 15 false yes. Too strict: harmful list includes words that are harmless when the ingredient is the same type: "vanilla yogurt -> Yogurt, vanilla, low fat" (false no), "blackberry Greek yogurt -> ...nonfat...CHOBANI", "canned black olives -> Olives, ripe, canned", "fried dumplings -> fried" (my set penalised fried even when ingredient says fried), "toasted bread -> toasted", "cold watermelon -> Watermelon, raw". False yes: ingredient words matching incidentally ("half and half" -> pork shank half; "stew meat" -> Stew, beef; "lamb loin chop" NZ imported; "yam" -> Mountain yam; "sage" -> Spices ground). Guidance: restrict residual penalties to a small core (cooked/fried/dried/juice/oil/frozen), ignore low fat/nonfat for yogurt/cheese when ingredient is flavored dairy, require matching on multiword phrases (half and half) rather than isolated tokens, and add bonus for adjacent bigram matches. Brand/Chobani suffixes must be ignored. Calibrate toward 40-45% yes rate.

## Slot 7 - Preparation-State Equivalence (variant 3/4) - val accuracy 0.7316
Slot 7 (prep-state v3): ordinal processing-level scale (raw 0, cooked 1, canned 2, dried 3, smoked/pickled 4, fried 5), state score from level gap, plus identity coverage, bigram bonus, product-switch and low-fat penalties. Accuracy 0.732 (best so far), yes 30%. 84 false no, 18 false yes. The low-fat/nonfat penalty caused many false no on flavored yogurt: "vanilla yogurt -> Yogurt, vanilla, low fat", "vanilla Greek yogurt -> nonfat/lowfat", "peach Greek yogurt -> CHOBANI nonfat". Yogurt matches with low-fat variants ARE labelled substitutable, so do not penalise low-fat on yogurt (cottage cheese low-fat stays NOT though; apply dairy penalty only for cheese). Other false no: seed/arils words ("pomegranate seeds -> Pomegranate, raw", "amaranth seed -> grain uncooked"), "fresh swordfish steak -> Fish, swordfish, raw" (head 'steak' missing: head noun should skip cut words like steak, fillet, chunks, slices), brand names (SILK, Dannon). False yes: category-prefix matches where USDA is a specific subtype (NZ lamb shank, Mountain yam, beaked hazelnuts, tri-tip for sirloin tip, "half" in pork shank half). Guidance: skip cut/part nouns (steak, fillet, seeds, slices, segments, florets) when choosing head; penalise rare qualifiers in USDA (Mountain, beaked, imported, New Zealand) absent from ingredient; require phrase-level match.

## Slot 8 - Preparation-State Equivalence (variant 4/4) - val accuracy 0.7158
Slot 8 (prep-state v4): logistic additive score: coverage of head words (cut nouns like steak/seed skipped), synonym table, state-class compatibility, product-form penalty, rare-qualifier penalty, cheese low-fat penalty. Accuracy 0.716, yes-rate 51% (balanced: 60 false yes, 48 false no). Synonym table and cut-skipping reduced false no but false yes rose: items whose state conflict is not detected because ingredient states are in a different position: "cooked ground turkey patties -> broiled" (cooked verbs differ but the same class, labelled NOT), "dried fish ground into powder -> dried and salted", "whole flaxseeds -> Flaxseed, ground" (ground vs whole not penalised since 'ground' was in the trivial list), "butternut squash cubed -> cooked, baked" (ingredient unmarked vs USDA cooked: should penalise), "half and half" token confusion, spaghetti sauce -> frozen entree. Guidance: do NOT treat ground/whole as trivial; penalise USDA cooked-state when ingredient is unmarked fresh produce; penalise ingredients with "cooked X" paired with USDA of a different form (patties/crumbles); handle the half-and-half phrase; keep synonym table (para nuts=brazil, mandarin=clementine, apple puree=applesauce, mandarin/clementine). Next rubric: look at other dimensions with this stronger base.

## Slot 9 - Preservation and Form Match (variant 1/4) - val accuracy 0.7053
Slot 9 (form v1): form-class detection (fresh, frozen, canned, dried, paste, powder, juice, oil, sauce, cooked) with a mismatch-cost matrix, +identity coverage and head match. Accuracy 0.705, yes 35%. 80 false no / 32 false yes. Identity/form dimension is stuck near 0.70-0.73; all my programs share the same residual errors. Persistent false yes (same rows repeated across slots): cottage cheese vs lowfat/lactose-reduced/with vegetables, "lean ground turkey" vs "Turkey, Ground, raw", "dried pinto beans -> from dried, fat added", "flour tortilla -> Taco...", "lamb loin chop -> New Zealand imported", "vanilla yogurt -> Frozen yogurt" (frozen is a name-bearing form, mismatch must be heavy when 'frozen' modifies product noun such as frozen yogurt/entree), "dried fish ground into powder". Persistent false no: brand-named USDA entries (Ritz, Silk, Quaker, Malt-O-Meal, Powerade), cut terms (pork loin chop, pollock fillets, pomegranate seeds), vegan/tofu mayo, "peppers and onions cooked, fat added", variety words (Bing, sweet). Guidance: brand USDA entry with a category word match should score medium-high; treat a hierarchical USDA head (first segment) as category when ingredient head appears in later segments; ignore fat-added/seasoning tails when ingredient is a prepared dish.

## Slot 10 - Preservation and Form Match (variant 2/4) - val accuracy 0.6895
Slot 10 (form v2): position-weighted identity over USDA segments (earlier segment = higher weight), preservation-set agreement (canned/frozen/dried/paste/powder/juice/pickled/smoked), product-word penalty, extra-specificity penalty. Accuracy 0.689 (weaker than the penalty-cascade programs), yes 40%. Weighting by segment position punishes valid hierarchical USDA names ("Beef, steak, sirloin", "Lettuce, cos or romaine", "Pork, fresh, loin" ), causing false no. False yes: cooked/state differences undetected because preservation set ignores cooking ("frozen escarole -> Escarole, cooked", "papaya seeds -> Papayas, raw", "toasted brazil nuts -> Brazil nuts", "whole flaxseeds -> ground"), and low sodium/deli/decaf descriptors (tea decaffeinated, deli turkey, tomato juice low sodium, cottage cheese variants). Insight: top programs so far are those that (a) take any-segment word matches, (b) subtract fixed penalties for USDA-side modifiers absent from ingredient (decaf, low sodium, with vegetables, fat free, imported, cooked), and (c) score synonyms. Next programs: use any-segment matching without position decay, add a USDA-modifier penalty list including decaffeinated/lactose/with vegetables/deli/imported, treat 'cooked' USDA vs unmarked ingredient as mismatch, and add synonym handling for the chronic false-no rows (grapes american/concord, cocoa dutch, queso).

## Slot 11 - Preservation and Form Match (variant 3/4) - val accuracy 0.7289
Slot 11 (form v3): hand-weighted linear model over ~14 features (coverage, head, head-in-first-segment, exact first segment, extra first-segment words, new product form, lost product form, preservation agree/only-one-side/conflict, USDA modifier count, brand, long USDA). Accuracy 0.729 at yes-rate 43%: best balanced result (43 false yes, 60 false no). Feature-linear structure with a USDA-modifier list works well. Remaining false yes: "frozen yogurt" (frozen as name-bearing word - add frozen yogurt/dessert to product forms), "papaya seeds -> Papayas, raw" (seeds are a different part), "toasted/cooked X -> X raw", "amaranth flour -> Flour, amaranth", cottage cheese variants, "lean ground turkey -> Turkey, Ground, raw", "Tortillas ready-to-bake shelf stable". False no: synonyms (mandarin = clementine, linseed = flaxseed, pinyon = pine nut, concord = american grape), cut/part forms (pork loin chop, sea bass cooked dry heat), brands (Ritz, Quaker, Malt-O-Meal), cooked descriptors "dry heat". Guidance: keep linear feature design; add features for 'part mismatch' (seed/leaf/skin/bone vs flesh), 'dry heat/moist heat' as cooked, more synonyms (linseed, jamun), brand-name uppercase tokens neutral, and cocoa butter->'Oil' type reversals (ingredient noun is a fat, USDA starts with Oil).

## Slot 12 - Preservation and Form Match (variant 4/4) - val accuracy 0.7143
Slot 12 (form v4): identity tiers (8/5.5/4/2/0) plus gate penalties (product form, plant part, preservation, USDA modifiers, brand) and exact-first-segment bonus. Accuracy 0.714, yes 39%, but 37 rows abstained because discrete tiers create many exact ties at the threshold; avoid coarse tiers and add continuous terms (coverage fraction, small length terms) to break ties. Errors: 41 false yes, 57 false no. False yes: cooked-vs-unmarked not penalised when ingredient already says toasted/cooked ("toasted amaranth flour -> Flour, amaranth", "toasted cornbread -> prepared from mix", "toasted rice bran"), "concord grapes -> muscadine" (synonym wrongly aligned), "half and half" token collision, "chicken neck -> cooked simmered", chrysanthemum cooked, yam variants. False no: Mission/GENERAL MILLS/Malt-O-Meal brand entries for generic cereals/tortillas, "baked sea bass -> cooked, dry heat" (baked ~ dry heat), "amaranth seed -> grain uncooked", "granada/Indian date" odd synonyms, "romaine hearts -> Lettuce, cos or romaine" (head 'hearts' not skipped), "pollock fillets". Guidance: add dry heat/moist heat as cooked, treat uncooked as raw, skip 'hearts' and 'fillets' as part words, treat brand-uppercase USDA entries by matching generic words (cereal, tortilla) to the first segment, and add phrase-level handling for 'half and half'. Always add a continuous tie-breaker.

## Slot 13 - Nutritional Profile Proximity (variant 1/4) - val accuracy 0.6658
Slot 13 (nutrition v1): keyword table mapping foods to approximate per-100g macro classes (fats, sugars, grains, nuts, cheese, meats, fish, produce, fruit, spices...), macro-distance proximity plus identity overlap. Accuracy 0.666 (lowest so far), yes 37%. Macro-class proximity adds almost no signal over identity: wrong-pair classes are usually the same macro class (cottage cheese lowfat, turkey patties broiled, chuck roast braised, vanilla yogurt vs frozen yogurt all share macros), so it cannot separate the false yes rows, and the near-misses are state/descriptor differences, not nutrition. It does reasonably flag real class swaps (hazelnut->oil, coconut yogurt->avocado oil, kidney->kidney beans). False no come from my overlap term: synonyms (linseed, filberts, para nuts, clementine), brand names (Mission, Hershey's), multiword USDA hierarchy ("Beef, variety meats, tongue", "Apples, raw, golden delicious"). Guidance: for macro programs, use macro class mainly as a hard-penalty gate for class swaps (fat vs protein vs produce) and rely on a good identity base; do not let macro-class equality alone produce high scores; compare wet vs dry and raw vs cooked energy density (cooked/dried change kcal/100g), and fat-reduced vs full-fat markers (reduced fat, lean, nonfat, lowfat) as macro shifters. Add synonyms.

## Slot 14 - Nutritional Profile Proximity (variant 2/4) - val accuracy 0.7184
Slot 14 (nutrition v2): identity coverage plus a "macro swing" penalty from shifter words (dried, powder, fried, lean, nonfat, reduced, juice, sweetened...) summed per side and differenced, product-class swap penalty, fat-part penalty. Accuracy 0.718, yes 34% (29 false yes / 78 false no). Fewer false yes, but too conservative. False no: shifters penalised where the labels accept them: "dried apple rings -> Apples dehydrated", "dried favas -> Broadbeans raw", "glass noodles -> dehydrated", "sauteed peppers and onions -> cooked, fat added", "smoked salmon lox -> smoked" (should match), plus wildcard USDA variants (bison -> Buffalo, wild raspberries, Northern Plains, 'microwave popcorn'). Also synonyms (bison=buffalo, pinyon, granada, romaine hearts). False yes: same as before (cooked vs fresh unflagged since 'cooked' shifter is tiny, "papaya seeds", "toasted brazil nuts", "hazelnuts beaked", "dried pinto -> from dried, no added fat", "lamb liver sliced -> cooked pan-fried"). Guidance: make shifter penalty apply only when one side has the shifter and the other lacks it AND the ingredient does not mention the shifter-equivalent; give cooked a real penalty (1.5-2) when only USDA side is cooked; add bison/buffalo, wild-variety neutral words; handle "variety meats and by-products" as organ category; keep it around 40% yes by lowering strictness on multi-segment USDA hierarchies.

## Slot 15 - Nutritional Profile Proximity (variant 3/4) - val accuracy 0.6974
Slot 15 (nutrition v3): canonical lexicon (alias to canonical food) then coverage, head and a macro-category agreement bonus (fat/sugar/starch/nut/dairy/meat/seafood/legume/produce/fruit/liquid), density-shifter and cooked-vs-fresh penalties. Accuracy 0.697, yes 35%. 34 false yes / 81 false no. Aliasing helped some synonyms but accuracy did not improve: errors are not from missing synonyms but from conservative penalties and from labelled-NOT rows that look perfect. Persistent false yes: "toasted brazil nuts", "whole flaxseeds -> ground", "yam -> Mountain yam", "dried pinto beans -> from dried", "cooked bison round steak -> Buffalo cooked (Shoshone Bannock)", "black tea -> iced bottled diet", cut-specific meat ("lamb shank -> NZ imported hind-shank", "beef shank crosscuts"). False no: parentheses brand entries (Ritz, Wheat Thins, Quaker, Malt-O-Meal), "ox tongue", "dried apple rings -> dehydrated" (dried=dehydrated synonym lacking!), "pecans unroasted", "ground pecans", "wild raspberries", "durian raw or frozen", "pickle loaf". Guidance: add dried=dehydrated equivalence, treat 'unroasted/uncooked/raw' equally, treat USDA 'diet/bottled/iced' as modifiers for beverages, and penalise USDA-only region/brand qualifiers only mildly. Ceiling around 0.72 suggests label noise; avoid over-tuning and diversify instead.

## Slot 16 - Nutritional Profile Proximity (variant 4/4) - val accuracy 0.6868
Slot 16 (nutrition v4): information-weighted overlap: macro-flipping words (oil, juice, powder, dried, fried...) weigh high, low-info words (raw, fresh, trimmed, choice...) weigh low; score = shared weight minus 0.9*missing ingredient weight minus 0.35*extra USDA weight; product swap penalty. Accuracy 0.687, yes 41%. Weighted-overlap is no better than the penalty cascade (0.70-0.73), and is hurt by long hierarchical USDA names, since extra USDA words and missing ingredient words both count. False no: "stew meat -> Beef, stew meat" (!), "poultry neck pieces simmered -> Chicken neck", "crawfish tails boiled -> Crustaceans, crayfish, moist heat", "romaine hearts -> Lettuce cos or romaine", "asadero -> Cheese, mexican, queso asadero", "ground pecans -> Pecans, unroasted", brands again. False yes: "chicken neck -> cooked, simmered", cooked-vs-fresh states, "stew meat -> Stew, beef" (word shuffle confusion), "palm oil -> Vegetable oil, palm kernel", dietary modifiers. Guidance for remaining slots: (1) generic umbrella words (poultry->chicken/turkey, crustacean->crayfish, lettuce, beef) should be given as category equivalents; (2) ingredient parts (neck, tongue, tail) must match USDA word; (3) distinguish USDA 'fat free/lowfat/with X' additions as penalties; (4) compute match on ordered phrase when possible (stew meat vs Stew, beef).

## Slot 17 - Specificity and Generality Alignment (variant 1/4) - val accuracy 0.7421
Slot 17 (specificity v1): head present +3, ingredient modifiers found in USDA +1.8 / missing -1.4, USDA qualifiers unexplained by ingredient penalised by tier (noticeable modifiers -1.6, primary-name extras -0.9, tail descriptors -0.25), generic-ingredient+generic-USDA bonus, dropped-qualifier penalty, cooked mismatch. Accuracy 0.742 (best so far), yes 33%, 21 false yes / 77 false no. Modifier-tier penalties (tail descriptors almost free) fit the data well. Remaining false no come from category words counted as "extra qualifiers": "swordfish -> Fish, swordfish", "crayfish -> Crustaceans, crayfish...", "pork loin chop -> Pork, fresh, loin...", "romaine hearts -> Lettuce, cos or romaine", "chuck roast -> Beef, chuck", "pork breakfast sausage -> Pork sausage", plus synonyms (mandarin -> Clementine) and brands. False yes: "stew meat -> Stew, beef", "dried radish slices -> Radish", cooked/dried vs raw mismatch not weighted enough, region/type variants (NZ lamb, beaked hazelnuts, Buffalo Shoshone). Guidance: add a category-word list (fish, beef, pork, lamb, chicken, turkey, nuts, seeds, cheese, lettuce, crustaceans, cereals, oil, fruit, vegetables) that is free as a first-segment word; give 'dried' mismatch a higher penalty; keep tiered qualifier logic; flag first-segment word order inversions (stew meat vs Stew, beef) via head-in-first-segment check.

## Slot 18 - Specificity and Generality Alignment (variant 2/4) - val accuracy 0.7316
Slot 18 (specificity v2): ratio score gain/(gain+loss): identity term gains (head 2.5, modifiers 1.5), losses for USDA descriptors by tier (noticeable, state, first-segment, tail), category words in first segment free, ingredient states missing in USDA penalised. Accuracy 0.732, yes 37%, 32 false yes / 70 false no. Category-free list was a mistake for transforming words: I put oil, syrup, sauce in the category list, causing "hazelnut -> Oil, hazelnut", "flaxseeds -> Oil, flaxseed" false yes. Only genuine taxonomy nouns (fish, beef, pork, lamb, cheese, lettuce, crustaceans, nuts, cereals) may be free; product-transforming nouns (oil, juice, syrup, sauce, flour, soup) must remain penalties. Other false yes: "stew meat -> Stew, beef", "smoked lamb chop -> Lamb, chop" (smoked dropped), "dried fish", "papaya seeds", "half and half" token collision, "pollock fillets -> Alaska ... may contain additives". False no: "navel orange -> Oranges, raw, all commercial varieties", "cervelat -> Thuringer, cervelat, summer sausage" (long synonym lists), "lamb kidneys -> NZ imported", brand names, "vanilla soy yoghurt -> SILK", "lima beans and corn buttered -> fat added" (butter~fat added), "ox tongue", "granada". Guidance: treat variety/brand tokens as neutral when ingredient head present in first or second segment; implement butter/fat added equivalence; handle plural/spelling variants; keep tiered penalties.

## Slot 19 - Specificity and Generality Alignment (variant 3/4) - val accuracy 0.7316
Slot 19 (specificity v3): token LCS (forward and hierarchy-reversed USDA order, plus per-segment) after dropping neutral words, set coverage, specificity gap (extra first-segment words, taxonomy words free), product-form penalty, modifier asymmetry. Accuracy 0.732, yes 36%, 30 false yes / 72 false no. Same plateau. Putting cooked/fried/dried into the modifier list was useful but dropping "raw/toasted/ground" as neutral caused false yes: "pollock fillets raw -> cooked" (because raw is dropped, the conflict is invisible), "toasted amaranth flour/brazil nuts/cornbread" (toasted dropped), "whole flaxseeds -> ground", "pinto from dried". Rule: never drop state words (raw, cooked, toasted, ground, whole) from comparison; treat them as paired features: conflict if both sides specify different states, mild if only USDA does. False no keep recurring: "vanilla yogurt -> low fat milk, flavors other than fruit", "canned black olives -> canned (small-extra large)", "apple purée -> Applesauce", "pinyon kernels -> Pine nuts", "boneless pork chop -> Pork, loin chops", brands (Quaker, Wheat Thins), variety "golden delicious". Guidance: handle yogurt flavour entries, size parentheticals, purée=sauce for fruit, pinyon/pine, and treat 'whole' as meaningful against 'ground'. We seem to be on a ceiling near 0.74; focus on varied designs not tuning.

## Slot 20 - Specificity and Generality Alignment (variant 4/4) - val accuracy 0.7263
Slot 20 (specificity v4): structured record comparison: identity coverage, explicit state classes (raw/cooked/fried/dried/canned/smoked/pickled) with a pairwise state-cost table (softened when one side is silent), shape (ground vs whole), first-segment extras, product-form swap, diet words. Accuracy 0.726, yes 41%, 40 false yes / 64 false no. Better balance than most. The "silent side" softening (+0.8) is too generous: "toasted amaranth flour/brazil nuts/rice bran -> unmarked", "yam cubed -> cooked", "lamb liver sliced -> cooked pan-fried", "papaya seeds -> Papayas raw" were labelled NOT, so a one-sided cooked/toasted marker is a real mismatch (about 2 points). Other false yes: "plain kefir -> lowfat strawberry LIFEWAY" (flavor added), "stew meat -> Stew, beef / Beef stew canned entree" (stew is a dish form word: must stay a penalty), "hazelnuts beaked", "split peas from dried, fat added", cottage cheese lowfat. False no: "chicken flats -> wing", "navel orange -> Oranges, raw, all commercial varieties", "mandarin orange -> Clementine", "pork breakfast sausage -> Pork sausage", "skin-on chicken -> meat and skin", "high fructose corn syrup -> Syrups, corn, high-fructose" (hyphenated token split), "canned...drained -> canned (small-extra large)". Guidance: tokenise hyphens as separate words; treat 'skin-on' = 'meat and skin'; fruit variety (navel, mandarin, Bing) as neutral; penalise one-sided cooked markers.

## Slot 21 - Lexical and Token Overlap (variant 1/4) - val accuracy 0.7
Slot 21 (lexical v1): content-token recall, first-segment precision, Jaccard, bigram order agreement, head hit, state agree/conflict, form/modifier penalties. Accuracy 0.700, yes 45%, 52 false yes / 62 false no. Lexical overlap alone is a weak discriminator: false yes are rows whose tokens fully overlap but differ by state or composition ("dried pinto beans -> from dried", "toasted cornbread -> prepared from mix", "cooked bison -> Buffalo cooked Shoshone", "reduced-fat pecan butter -> Peanut butter, reduced fat" where pecan/peanut similarity... head 'butter' + 'reduced-fat' overlap pass: overlap that comes only from modifiers or head fragment must be discounted, as the rubric says), "chicken ham -> Ham, minced" (modifier chicken missing). False no: low-overlap truths needing knowledge: "pinyon -> pine nuts", "Indian date -> tamarind", "sufu -> Tofu fermented", "crawfish -> crayfish moist heat", "smoked salmon lox", "asadero -> queso asadero", milk and cream -> half and half. Guidance: when ingredient has 2+ content words and the non-head word is missing in USDA, subtract strongly (pecan vs peanut, chicken vs ham); count state words once; add lexicon knowledge for odd names; transform to concept-level matching rather than bare tokens. Include stem-prefix matching (pecan/peanut must NOT match; 4-char prefix is too loose).
